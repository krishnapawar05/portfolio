# 🌌 Krishna G. Pawar — Personal Developer Portfolio

> **Full-Stack Developer & AI Enthusiast**  
> Modern, cinematic developer portfolio built with React 19, TypeScript, Vite, Tailwind CSS, GSAP, Framer Motion, and HLS streaming.

---

## ⚡ Tech Stack

- **Core**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Tailwind CSS Animate
- **Animations**: GSAP (Timeline, ScrollTrigger), Framer Motion
- **Media**: hls.js (Mux HLS background video stream with fallback)
- **Icons**: Lucide React & Custom SVG

---

## 🚀 Key Features

- **Cinematic Dark Theme**: Custom HSL tokens, grain/halftone textures, and ambient lighting.
- **Interactive 3D Cards**: Project cards with real-time pointer perspective tilt and specular lighting.
- **HLS Video Streaming**: Live HLS background video stream with graceful offline/static fallback.
- **Projects Showcase**: 6 featured projects with detailed architecture modals (SmartVision, CivicTrack, Genetic Purity AI, GrainVision, SaveHer, CurioBattle).
- **Floating Pill Navigation**: Fixed navbar with active section detection, resume download, quick social links, and accessible mobile menu.
- **Verified Contact Channels**: Direct email compose action, clickable phone number, and verified GitHub & LinkedIn links.

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18+)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/krishnapawar05/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
# Type check and build
npm run build

# Preview production build locally
npm run preview
```
